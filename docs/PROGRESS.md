# Текущий статус проекта

Обновлено: 24 октября 2026 года.

## Реализовано в репозитории

- Публичная справочная с поиском, разделами курортов и ссылками на первоисточники.
- Раздел «Инструкторы»: индивидуальные, групповые и детские занятия, ориентиры прогресса, сезонный калькулятор, страницы по курортам/форматам, форма запроса.
- Справочные страницы: дорога, парковки, прокат, безопасность, жильё и партнёрам.
- Пререндер маршрутов, SEO metadata, canonical и sitemap.
- Заявки хранятся в PostgreSQL; просмотр и смена статуса доступны только авторизованным администраторам.
- Telegram-уведомления доступны при наличии `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
- В админке можно вручную обновлять статус курорта. Главная показывает только записи со временем проверки не старше 24 часов.
- Админка собирается отдельным Docker-образом и разворачивается отдельным loopback-сервисом.
- Удалены встроенные тестовые учётные данные; seed требует `ADMIN_EMAIL` и `ADMIN_PASSWORD`, backend — `JWT_SECRET`.

## Проверки

- Frontend: production build и prerender проходят.
- Admin: TypeScript и production build проходят.
- Backend: Prisma Client generation и TypeScript build проходят.
- Автоматическая проверка Docker Compose в локальной среде требует настоящего `backend/.env.production`; этого файла в репозитории намеренно нет.

## Нужны внешние настройки или подтверждённые данные

- Заполнить production-секреты и выполнить deploy в окружении с доступом к PostgreSQL.
- Настроить DNS/HTTPS virtual host для админки в общем reverse proxy; deploy не меняет общую Nginx/Certbot-инфраструктуру.
- Для Telegram задать bot token и chat ID.
- Проверить и подтвердить цены 2026/27 у курортов; калькуляторы пока маркированы сезоном 2025/26.
- Настроить цели Метрики и отправить sitemap/ключевые URL в Яндекс Вебмастер.
- Для политики обработки персональных данных, контактов и страницы владельца нужны подтверждённые реквизиты оператора и контакты.
- Публиковать отзывы только после получения реальных отзывов с разрешением на размещение.
- Для английской версии необходим отдельный переведённый и проверенный контент, включая сценарий отправки заявки.
- Партнёрские предложения по прокату и трансферу появятся после подтверждения реальных партнёров и условий.
- Оплата через ЮKassa не подключена: нужны merchant-доступ, юридические документы и правила возвратов.
